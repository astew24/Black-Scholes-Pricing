European option pricing with real market data and interactive exploration.

A Python package that calculates fair value and risk sensitivities for European call and put options using the Black-Scholes model, with live stock data, a Streamlit web interface, and a CLI.

View repository Explore interfaces

What it does

Prices options

Applies the closed-form Black-Scholes solution for European calls and puts given spot, strike, expiry, volatility, and risk-free rate.

Calculates all five Greeks

Delta, gamma, theta, vega, and rho — the sensitivities that tell you how the option value moves as market conditions change.

Uses live market data

Fetches real-time stock prices and implied volatility from Yahoo Finance, and approximates the risk-free rate from Treasury yields.

The formula

The model has a closed-form solution under lognormal returns, constant volatility, and no dividends.

C = S·N(d₁) − K·e−rT·N(d₂)

d₁ = [ln(S/K) + (r + σ²/2)·T] / (σ√T)
d₂ = d₁ − σ√T

Greeks

Each Greek measures a different dimension of option risk.

Δ Delta Price change per $1 move in the underlying stock.
Γ Gamma Rate of change of delta — how quickly your hedge drifts.
Θ Theta Value lost per day as the option approaches expiry.
ν Vega Value change per 1% move in implied volatility.
ρ Rho Value change per 1% move in the risk-free rate.

Three ways to use it

Streamlit web app

Interactive sliders for every parameter. Prices and Greeks update instantly as you move inputs.

streamlit run black_scholes/streamlit/app.py

Command line

Price any ticker directly from the terminal. Pass a strike, expiry, volatility override, or let it fetch live values.

black-scholes AAPL --plot

Python API

Import black_scholes and calculate_greeks directly into any script or notebook.

from black_scholes import black_scholes

Honest limits

Black-Scholes assumes constant volatility, no dividends, and frictionless markets. Real options markets deviate from these assumptions, particularly around earnings, dividends, skew, and early exercise (American options only).
